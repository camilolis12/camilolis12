###  Proyectos Destacados

#### 1) ServicExpress — Plataforma de Conexión de Servicios Eléctricos *(Proyecto Académico)*
> Plataforma orientada a conectar usuarios que demandan servicios eléctricos con técnicos calificados, facilitando la gestión integral de requerimientos y cotizaciones.

- **Tecnologías:** `Java` · `Spring Boot` · `MySQL` · `HTML5` · `CSS3` · `JavaScript`
- **Funcionalidades Clave:**
  -  Control de acceso seguro con registro, autenticación y manejo de roles.
  -  Catálogo interactivo de servicios con indexación por etiquetas dinámicas y filtros de búsqueda.
  -  Módulo de valoración y reseñas bidireccionales entre usuarios y prestadores de servicio.
  -  Sistema de mensajería directa y gestión estructurada de cancelaciones y solicitudes.

```
[ Cliente / Técnico ] <---> [ Frontend Web ] <---> [ REST API Spring Boot ] <---> [ Base de Datos MySQL ]
```

####  2) Sistema de Soporte a la Decisión para Gestión de Inventario *(Proyecto de Grado)*
> Modelo de analítica predictiva enfocado en optimizar el abastecimiento y la rotación de stock en microcomercios del sector ferretero.

-  **Propósito:** Asistir la toma de decisiones comerciales a través del análisis de demanda, generación de sugerencias de reabastecimiento y mitigación de inventario de baja rotación.
-  **Estado Actual:** En formulación técnica y refinamiento del modelo algorítmico.
